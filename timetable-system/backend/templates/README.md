# Шаблон расписания

`timetable.xlsx` — первый лист «ТФ 3 курс типо» из предоставленного пользователем
файла «3курс расписание занятий ко ро (5).xlsx». Остальные листы, названия групп,
занятия, аудитории занятий, комментарии и гиперссылки удалены. Оформление,
временная сетка, шапка, блок утверждения и подписи сохранены.

Экспорт заполняет этот шаблон данными приложения. Курс и номер осеннего семестра
(2 × курс − 1) подставляются автоматически. Учебный год 2026–2027, основание
обучения и ФИО подписантов остаются такими, как в выбранном образце. Для изменения
этих реквизитов нужно обновить шаблон, сохранив координаты его основных блоков.

До восьми групп используются исходные восемь блоков, незанятые остаются пустыми.
Для большего числа групп сетка продолжается вправо. Дополнительные времена пар
и суббота добавляются только при наличии таких занятий у выгружаемой кафедры.
Вертикальное объединение аудиторий из образца сохраняется только при совпадении
новых значений: различающиеся аудитории выводятся отдельно, без потери данных.
